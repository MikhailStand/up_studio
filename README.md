# Демонстрационный сайт студии пилатеса

Одностраничный демонстрационный сайт студии пилатеса: направления для взрослых и детей, тарифы и особенности занятий. Контактные данные обезличены.

## Что есть на сайте

- отдельные направления и цены для взрослых и детей;
- занятия на коврике, воздушный фитнес и детская воздушная гимнастика;
- адаптивная версия для компьютеров и телефонов;
- обезличенный контактный блок и демонстрационная карта;
- автоматическая публикация через GitHub Pages.

## Локальный запуск

Понадобится Node.js 22.13 или новее.

```bash
git clone <адрес-репозитория>
cd up_studio
npm install
npm run dev
```

После запуска откройте адрес из терминала — обычно `http://localhost:3000`.

Проверка готовой сборки:

```bash
npm run build
```

Проверка статической сборки для GitHub Pages:

```bash
npm run build:pages
```

## Где менять содержимое

- `app/page.tsx` — направления, тарифы, тексты, телефон и ссылки;
- `app/globals.css` — оформление и адаптивная версия;
- `app/layout.tsx` — заголовок, описание и превью ссылки;
- `public/` — локальные изображения и служебные файлы.

## Публикация

После отправки изменений в ветку `main` workflow из `.github/workflows/deploy-pages.yml` собирает и публикует сайт.

При первом запуске откройте в репозитории `Settings` → `Pages` и выберите `GitHub Actions` в разделе `Build and deployment`.
