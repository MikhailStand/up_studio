# «Вдохновение в пути» — сайт студии йоги

Одностраничный сайт для студии йоги «Вдохновение в пути» в Королёве. Он помогает посетителю быстро посмотреть направления занятий, форматы групп, цены, массаж, абонементы и связаться с администратором.

Сайт адаптирован для компьютеров и телефонов. На мобильных устройствах карточки занятий и массажа листаются пальцем, а бургер-меню позволяет сразу перейти к нужному разделу.

## Что есть на сайте

- направления йоги, пилатеса, растяжки и фитнеса;
- продолжительность занятий и размер групп;
- групповые и персональные форматы;
- цены на занятия;
- виды массажа и стоимость сеансов;
- абонементы и специальные предложения;
- адрес, телефон и ссылка на Яндекс Карты;
- быстрые кнопки перехода и мобильное меню.

## Технологии

- React;
- TypeScript;
- Vinext и Vite;
- CSS;
- Cloudflare Workers для локального запуска и размещения.

## Как запустить сайт на компьютере

Понадобится Node.js версии 22.13 или новее.

1. Склонируйте репозиторий:

   ```bash
   git clone https://github.com/MikhailStand/vdohnovenie_v_puti.git
   cd vdohnovenie_v_puti
   ```

2. Установите зависимости:

   ```bash
   npm install
   ```

3. Запустите режим разработки:

   ```bash
   npm run dev
   ```

4. Откройте в браузере адрес, который появится в терминале. Обычно это `http://localhost:3000`.

Для проверки готовой сборки выполните:

```bash
npm run build
```

## Где менять содержимое

Основные файлы проекта:

- `app/page.tsx` — тексты, направления, виды массажа, цены, абонементы, телефон и ссылки;
- `app/globals.css` — цвета, шрифты, размеры, отступы и мобильная версия;
- `app/layout.tsx` — название сайта, описание и картинка для превью ссылки;
- `public/` — изображения и служебные файлы, доступные посетителям;
- `config/hosting.json` — нейтральная конфигурация дополнительных сервисов Cloudflare.

### Как изменить занятие или массаж

В начале файла `app/page.tsx` находятся списки `directions` и `massages`. У каждого элемента можно изменить:

- `title` — название;
- `text` — описание;
- `duration` — продолжительность;
- `group` — размер группы;
- `image` — адрес фотографии.

Цены и абонементы находятся ниже в том же файле в разделах `prices`, `massage-prices` и `offers`.

## Как опубликовать сайт

Для проекта настроена автоматическая публикация через GitHub Pages. После каждого `git push` GitHub собирает сайт и обновляет публичную страницу:

<https://mikhailstand.github.io/vdohnovenie_v_puti/>

При первом запуске нужно один раз открыть в репозитории `Settings` → `Pages` и в разделе `Build and deployment` выбрать `GitHub Actions`. Затем открыть вкладку `Actions` и дождаться завершения процесса «Публикация сайта на GitHub Pages».

Для проверки именно GitHub Pages-сборки на компьютере выполните:

```bash
npm run build:pages
```

Готовые статические файлы появятся в `dist/client`.

Репозиторий также можно подключить к Cloudflare или другому хостингу с поддержкой Node.js и Vite.

Основная команда сборки:

```bash
npm run build
```

Папка `dist` создаётся автоматически и не добавляется в GitHub.
